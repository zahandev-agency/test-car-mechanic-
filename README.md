# AutoCare Pro - Car Mechanic Website

A professional, responsive website for a car mechanic business featuring modern design, trust-building elements, and strong call-to-actions.

## Features

### Homepage Sections
- **Hero Section**: Eye-catching banner with main value proposition and CTAs
- **About Us**: Professional description with trust indicators
- **Services**: 6 comprehensive auto services with icons and descriptions
- **Testimonials**: Customer reviews with star ratings
- **Contact Form**: Interactive form with validation
- **Footer**: Contact information, quick links, and social media

### Design Elements
- **Professional Color Scheme**: Deep blue (#1e3a8a) and orange (#ea580c)
- **Modern Typography**: Inter font family for clean readability
- **Responsive Design**: Mobile-first approach with breakpoints
- **Interactive Elements**: Hover effects, smooth scrolling, animations
- **Trust-Building**: Certifications, experience indicators, testimonials

### Technical Features
- **Responsive Layout**: Works on desktop, tablet, and mobile
- **Form Validation**: Client-side validation with visual feedback
- **Smooth Scrolling**: Navigation links scroll smoothly to sections
- **Mobile Menu**: Hamburger menu for mobile devices
- **Accessibility**: Semantic HTML and keyboard navigation support

## Deployment Options

### Option 1: Static Web Hosting
1. Upload all files to your web hosting provider
2. Ensure the folder structure is maintained
3. Point your domain to the index.html file

### Option 2: GitHub Pages
1. Create a new GitHub repository
2. Upload all files to the repository
3. Enable GitHub Pages in repository settings
4. Your site will be available at `https://username.github.io/repository-name`

### Option 3: Netlify (Recommended)
1. Create account at netlify.com
2. Drag and drop the entire folder to Netlify
3. Get instant deployment with custom domain options

### Option 4: Local Development Server
For testing locally:
```bash
# Using Python 3
python -m http.server 8000

# Using Node.js (if you have it installed)
npx serve .

# Then open http://localhost:8000 in your browser
```

## Customization Guide

### Updating Content
1. **Business Information**: Edit contact details in `index.html`
2. **Services**: Modify service descriptions and add/remove services
3. **Testimonials**: Replace with real customer reviews
4. **Images**: Replace placeholder images with your actual photos

### Styling Changes
1. **Colors**: Update CSS variables in `styles.css`
2. **Fonts**: Change font family in the Google Fonts link
3. **Layout**: Modify grid layouts and spacing in CSS

### Adding Functionality
1. **Contact Form**: Connect to a backend service or email provider
2. **Booking System**: Integrate with scheduling software
3. **Analytics**: Add Google Analytics tracking code
